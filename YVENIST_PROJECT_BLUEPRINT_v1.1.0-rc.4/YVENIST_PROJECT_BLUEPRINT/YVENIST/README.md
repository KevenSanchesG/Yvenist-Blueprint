# YVENIST — Núcleo de contexto

Esta pasta reúne o contexto de referência da empresa e do ecossistema Yvenist para que pessoas e agentes compreendam rapidamente o que é o projeto e onde encontrar sua documentação autoritativa. Release do Blueprint: 1.0.0.

## Conteúdo

- `YVENIST_MASTER_CONTEXT.md`: resumo de contexto e índice de leitura.
- `ECOSYSTEM_OVERVIEW.md`: visão do ecossistema, participantes e relações de valor.
- `PRODUCT_SURFACES_CATALOG.md`: catálogo das aplicações, interfaces e ferramentas consideradas, com status explícito.
- `CURRENT_STATE_BASELINE.md`: registro factual do estado observado do projeto em uma data específica.

## Regra contra duplicação

Esta pasta não é uma segunda documentação de requisitos. Regras detalhadas, especificações, políticas, decisões e planos pertencem às áreas especializadas descritas em `BLUEPRINT_ARCHITECTURE.md`. Os documentos desta pasta devem resumir e apontar para essas fontes, nunca manter cópias concorrentes.

## Cautela de status

Contexto informado por fundadores em conversas anteriores não equivale automaticamente a decisão formal ou situação técnica verificada. Diferencie sempre `APPROVED`, `PROPOSAL`, `ASSUMPTION`, `UNVERIFIED`, `BACKEND_DEPENDENCY`, `SUPERSEDED` e `REJECTED`. O baseline atual só poderá ser consolidado após auditoria das fontes e do repositório real.
